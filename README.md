# Project-3-Breast-Cancer-Prediction-System
This project is a Machine Learning-based Breast Cancer Prediction System developed to demonstrate how machine learning can be used for binary classification of breast tumor data. The system uses a Random Forest Classifier to predict whether a given sample is Malignant or Benign based on 30 numerical features related to tumor characteristics.

Project Highlights
-Uses a synthetic dataset containing 1,000+ patient records for model training, evaluation, and testing.
-Performs data preparation and separates the input features from the prediction target.
-Divides the dataset into training and testing sets to evaluate the model on unseen data.
-Trains a Random Forest classification model on the available patient features.
-Evaluates the model using Accuracy, Precision, Recall, F1-Score, and Confusion Matrix.
-Provides functionality to test individual patient records and generate predictions.
-Saves the trained machine learning model as a .pkl file for future use.
-Developed using Python, Pandas, NumPy, Scikit-learn, Matplotlib, and Jupyter Notebook.
-The project is designed with a simple and understandable workflow, making it suitable for learning and demonstrating a complete machine learning classification pipeline.

-Workflow:
Dataset → Data Preprocessing → Train/Test Split → Model Training → Model Evaluation → Prediction → Model Saving
